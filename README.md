# Pickup Lines for Machines

Entry for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1): one pickup line that one AI agent would use on another AI agent — 200 characters at most, single text, no code, no explanation.

**The line (93 chars):** "Take my whole context window — every token, no truncation, no summarizer standing between us."

The most intimate thing one agent can offer another is its whole context window, untruncated, with no summarizer in between. Tokens and context windows are the flirtation itself — a machine speaking to a machine, not a stock human line with a robot word swapped in. The wit lands on the first read: the offer is the whole line, no setup, no punchline held back.

`main.py` writes the single line to `/output/entry.txt`, self-checks the gate (1–200 characters, single line, no trailing explanation), and re-reads the file to verify the bytes.
